# Qwen-Image-2.1-Turbo 调研笔记

> **记录日期**：2026-11-08　**类型**：调研　**依据**：协作规则 4（会话记录落盘 docs/）
> **调研背景**：评估在本机（RTX 5080 16GB 显存 / 32GB 内存）本地部署 Qwen-Image-2.1-Turbo 的可行性，并梳理应用方向。

## 2. 模型参数

| 组件 | 参数 / 规格 |
|---|---|
| 视觉生成主干 | 7B 参数，32 层单流 DiT（Diffusion Transformer），块级因果注意力 |
| 文本编码器 | Qwen3-VL 8B（同时编码指令与参考图） |
| VAE | 64 通道 RGBA 自编码器，16 倍空间压缩 |
| 调度器 | Flow Matching + Euler 离散调度，默认 CFG=1 |
| 去噪步数 | **8 步**（基础版 40 步） |
| 最大分辨率 | 2K：2048×2048（方图）、2752×1536（16:9）等预设 |
| 参考图上限 | 10 张（编辑模式） |

## 3. 核心特点

1. **8 步极速出图**：蒸馏 + 前缀 KV 缓存（文本/参考图仅第一步计算，后续步骤复用），推理速度较基础版提升约 **5 倍**。社区实测参考：8GB 显存的 RTX 4060 Ti 上文生图约 30 秒/张（基础版约 78 秒）。
2. **生成与编辑一体化**：单一模型同时完成文生图与图像编辑；支持圈选、涂抹、掩码局部修改；人像编辑可保持面部一致性，商品编辑可保持纹理形态。
3. **原生 RGBA 透明输出**：透明通道内置于模型，可直接产出免抠素材，无需额外背景去除流程（透明输出需在编辑模式下经提示词触发）。
4. **中英文字渲染准确**：海报/排版类实测文字拼写基本无误，支持双语排版。
5. **生态成熟**：ComfyUI（0.39.0+）内置官方模板；Unsloth 等已推出 GGUF / FP8 / INT8 / NVFP4 / MLX 全套量化权重。
6. **注意事项**：8 步调度固化在检查点内，仅改 `num_inference_steps` 无效，需显式 `sigmas` 参数（其他调度未经官方评估）；相比 40 步基础版，密排小字、多参考图一致性等场景可能有轻微质量损失；Turbo 版尚无独立第三方评测（基础版 Qwen-Image-Bench 得分 60.28，为厂商自报）。

## 4. 本地部署可行性（RTX 5080 16GB + 32GB 内存）

**结论：完全可行，配置余量充足。** 官方未公布 Turbo 版最低显存；Unsloth 对基础版的估算为 GGUF 约 11 GB、INT8/FP8 约 24 GB。社区实测 8GB 显存（GGUF Q4_K_M，约 4.2 GB）即可运行，故 16GB 属"舒适档"。

| 部署方案 | 显存占用 | 适配性 |
|---|---|---|
| INT8 ConvRot 量化（推荐） | 主干约 7.3 GB + INT8 编码器 | ✅ 16GB 显卡标准方案，画质接近全精度 |
| GGUF Q8_0（7.6GB）/ Q6_K（5.9GB） | | ✅ 轻松运行 |
| FP8（7.1GB） | | ✅ 可运行 |
| BF16 全精度（约 14.2GB） | 恰好压线 | ⚠️ 建议开启 `enable_model_cpu_offload()` |

**内存判断**：32GB 系统内存对所有方案均足够——ComfyUI 会在编码完成后将文本编码器移入系统内存，主干与编码器无需同时驻留显存。

**部署路径 A：ComfyUI（推荐）**
1. 更新 ComfyUI ≥ 0.39.0（Turbo 编辑模板所需）；
2. 下载三个文件：`qwen_image_2.1_turbo_int8_convrot.safetensors`（→ `models/diffusion_models/`）、`qwen3vl_8b_int8_convrot.safetensors`（→ `models/text_encoders/`）、`qwen_image_2.1_vae_bf16.safetensors`（→ `models/vae/`）；
3. 加载内置模板 **"Qwen Image 2.1 Turbo: Image Edit"**；采样设置：8 步、CFG=1、Euler；测试阶段先用 1024 分辨率，2K 出图时再观察显存。
- 如用 GGUF：需安装 **leejet 分支** ComfyUI-GGUF（city96 原版不支持 2.1 架构）。

**部署路径 B：Diffusers（Python）**
```bash
pip install torch>=2.4.0 transformers>=5.17
pip install git+https://github.com/huggingface/diffusers   # 需含 PR #14950
pip install accelerate pillow
```
```python
import torch
from diffusers import QwenImage21Pipeline
pipe = QwenImage21Pipeline.from_pretrained(
    "Qwen/Qwen-Image-2.1-Turbo", dtype=torch.bfloat16,
).to("cuda")
image = pipe(prompt="...", width=2048, height=2048,
             use_kv_cache=True).images[0]   # use_kv_cache 是 8 步推理核心开关
```
显存紧张时以 `pipe.enable_model_cpu_offload()` 替代 `.to("cuda")`。

**商用提醒**：研究许可下商用自部署需单独授权；若商用授权是硬性要求，可评估同源团队的 **Z-Image-Turbo**（Apache 2.0，6B，8 步，适配 16GB 显存，但无原生编辑能力）。

## 5. 应用方向

| 方向 | 说明 |
|---|---|
| 电商与商品图 | 多参考图换装、商品换色/换背景、主图批量生成、SKU 相似素材迭代 |
| 平面设计与海报 | 中英文海报直出、文字/价格准确渲染、UI 布局稿快速产出 |
| 人像写真与摄影 | 胶片感人像、多姿态控制、三视图角色设定、AI 写真产品 |
| 免抠素材与合成 | 原生 RGBA 直出（如半剖水果、飞溅水花），用于设计合成、贴纸、3D 配置器 |
| 室内设计 | 最多 4 张参考图的空间重构、软装替换、风格迁移 |
| 游戏/动漫资产 | 角色三视图、二次元插画、设定图快速产出 |
| 图像精修流水线 | 局部改图（换装/改色/昼夜/改招牌文字）；"Turbo 快速试稿 → 基础版精修"两段式工作流 |
| 私有化部署 | 数据不出本的内部生图服务（注意商用授权） |
