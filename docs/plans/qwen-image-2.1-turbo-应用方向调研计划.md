# Qwen-Image-2.1-Turbo 应用方向开发调研计划

> **文档日期**：2026-11-08　**类型**：调研计划　**目标**：用 2–3 周时间，通过评分矩阵 + POC 实测确定下一个开发方向。
> **前提**：部署指南已就绪（`docs/guides/qwen-image-2.1-turbo-部署指南.md`）；硬件基线 RTX 5080 16GB / 32GB 内存。

---

## 1. 方法论

每个候选方向先过**评分矩阵**（桌面研究，不写代码），Top 2–3 方向再进 **POC 实测**（用已部署模型跑真实场景样例），最终在**决策门**（Decision Gate）评审后确定开发方向。评分项：

| 维度 | 权重 | 说明 |
|---|---|---|
| 技术契合度 | 30% | 是否用到本模型的差异化能力（多参考图编辑 / 原生 RGBA / 文字渲染 / 2K） |
| 落地可行性 | 25% | 16GB 显存能否支撑该场景的生产节奏（速度×批量） |
| 需求真实度 | 25% | 是否有可验证的真实需求 / 自用价值 |
| 合规风险 | 20% | 许可证、内容安全、数据隐私风险高低（反向计分） |

## 3. 重点方向调研卡片

### 卡片 A：电商商品图 / 模特换装

- **价值假设**：商家用"模特图 + 服装平铺图 + 配饰图"直接合成穿搭图，替代真人试拍，单张成本从数百元降至秒级本地算力。
- **用到的能力**：多参考图（模特/服装/包各一图）、身份保持、纹理保持；规则 4 已实测社区案例（人物+帽子+斜挎包合成成功）。
- **POC 设计**（预计 3 天）：
  1. 收集 3 组真实素材（模特、上衣、配饰各 1 图，共 3 组场景）；
  2. ComfyUI 编辑模板跑"保持图1人物，添加图2服装、图3配饰"，每组出 8 张；
  3. 人工评分：人物一致性 / 服装纹理 / 配饰形态（1–5 分）；记录单张耗时与显存峰值。
- **通过标准**：一致性均分 ≥ 4；可接受重试 ≤ 3 次/张。
- **风险**：① Qwen Research License **不允许商用自部署**——变现前必须申请商业授权或改走 0.1 元/张 API；② 生成图用于电商需符合平台 AI 内容标注规则。
- **许可证影响**：🔴 高——POC 可继续，商业化决策前必须拿到授权结论。

### 卡片 B：RGBA 免抠素材生产

- **价值假设**：设计/电商详情页常年需要"透明底素材"（水果飞溅、产品漂浮、贴纸元素）；本模型原生直出 Alpha 通道，省掉抠图工序。
- **用到的能力**：64 通道 RGBA VAE、透明背景提示词触发。
- **POC 设计**（预计 2 天）：
  1. 选 5 类高频素材主题（飞溅液体 / 漂浮产品 / 简笔贴纸 / 叶材 / 几何元素）；
  2. 每类 10 张，8 步 Turbo 直出；
  3. 用 Python 检查 Alpha 通道质量：边缘锯齿率、半透明过渡带宽度、非主体区 alpha 是否为 0（脚本可自动化）；
  4. 与传统抠图（rembg 等）做耗时与质量对照。
- **通过标准**：Alpha 边缘可用率 ≥ 80%（免后处理直接用）。
- **风险**：透明输出需在编辑模式下触发，T2I 模式的透明度触发率需实测；素材商用的版权归属需确认（生成内容条款）。
- **许可证影响**：🟡 中——自用/内部素材无碍，对外售卖素材需过授权与条款两道关。

### 卡片 C：中英文海报 / UI 布局稿（备选）

- **价值假设**：活动海报、Banner、UI 草稿的快速出稿，中英文小字渲染准确是核心卖点。
- **POC 设计**（预计 2 天）：3 组海报提示词（含指定价格、日期、双语标语），每组 Base 与 Turbo 各出 4 张，统计文字拼写正确率与排版可用率；已知风险点 = 密排小字。
- **通过标准**：短文案拼写正确率 ≥ 90%；密排小字场景允许失败，转人工排字。
- **许可证影响**：🟢 低（内部创意流程）。

### 卡片 E：图像精修流水线（备选）

- **价值假设**："Turbo 快速试稿筛选 → 基础版 40 步精修"两段式，把单项目出图等待时间削减约 65%（社区实测：78s→30s，编辑 167s→53s）。
- **POC 设计**：与卡片 A/C 合并进行——同一任务记录 Turbo 与 Base 的耗时/质量/重试率，得出两段式收益数据。
- **许可证影响**：🟢 低（自用提效）。

## 6. 初步建议（待 POC 验证修正）

1. **首选卡片 B（RGBA 素材）**：技术契合度与可行性双高（纯 T2I/编辑直出，无复杂多图编排），Alpha 质量可用脚本客观量化，POC 成本最低；即使不对外变现，自用提效价值也稳定存在。
2. **次选卡片 A（电商换装）**：商业价值上限最高，且能复用卡片 E 的试稿→精修数据；但受许可证制约最深，**必须在决策门前拿到 Q4 的授权结论**。
3. 卡片 C 作为 A/B 数据不足时的兜底方向；D/F/G/H 暂缓（契合度或需求度偏低）。
4. 所有 POC 产出的样例图、评分表、计时数据一律按规则 4 落盘 `docs/notes/`，决策门评审以落盘数据为准。
